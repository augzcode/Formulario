# Formulario

Sistema de cadastro de clientes desenvolvido em Python com Tkinter. O projeto permite cadastrar, consultar, atualizar e excluir clientes por meio de uma interface gráfica simples, armazenando os dados em um arquivo de texto (`clientes.txt`).

### Funcionalidades

* Cadastro de clientes
* Consulta de registros
* Atualização de dados
* Exclusão de clientes
* Validação de códigos duplicados
* Mensagens de sucesso, erro e confirmação através de caixas de diálogo

### Tecnologias Utilizadas

* Python
* Tkinter
* Manipulação de arquivos (`.txt`)
